# Floating UI (self-hosted)

Positioning for the site's own tooltips (`To_f_hint_*` in `share/js/Tools.js`).

- `@floating-ui/core` 1.8.0 — `floating-ui.core.umd.min.js` (global `FloatingUICore`)
- `@floating-ui/dom` 1.8.0 — `floating-ui.dom.umd.min.js` (global `FloatingUIDOM`, needs `FloatingUICore` loaded first)
