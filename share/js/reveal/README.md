# reveal.js (self-hosted)

HTML presentation framework for the talk decks under
`de/Superial-Zahlen/Vortraege/`.

- `reveal.js` 6.0.2 — `dist/reveal.js` (global `Reveal`)
- Plugins used: `dist/plugin/math.js` (MathJax integration)
- Stylesheets: `dist/reset.css`, `dist/reveal.css`, plus a per-theme CSS
  file in each talk deck's own folder (not part of this copy)

Source: https://revealjs.com (MIT, see `LICENSE`). Copied unchanged
from the npm package's `dist/` folder.
